# aval rebrand (dotfiles → aval)

Decision 2026-11-21: the repo becomes **aval**, a personal agent harness. "Aval"
is Spanish for a guarantee — someone vouches for something — which is the
harness's thesis: nothing counts as done without evidence (gates, strict TDD,
gitleaks, measure before deciding). It also contains "Alva".

Scope rules:
- Brand surfaces are renamed: binary, npm package, Go module, release assets,
  env vars, docs, hero.
- Live paths stay: the local checkout remains `~/dotfiles` (every symlink and
  the running session point there). Docs reference repo-relative paths so the
  folder name does not matter. New installs clone to `~/.aval`.
- "dotfiles" meaning hidden files (yazi comments) is not the brand; untouched.

- [x] T4 Docs: README presents aval and its meaning, guide, npm README, hero
- [ ] T5 GitHub: rename repo to aval, description and topics; full suite green; push
